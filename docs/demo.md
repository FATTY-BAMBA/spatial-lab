# 客戶示範腳本（15 分鐘）

對象：設計公司老闆／主案設計師。目標：用**他們自己的平面圖**，15 分鐘內從上傳走到可以簽的提案書，最後談試用。
演練紀錄與已知弱點：[`demo-rehearsal.md`](demo-rehearsal.md)。

**一句話定位**：「你們的平面圖丟進來，一分鐘後就是可以走進去的 3D、即時報價和實景效果圖，客戶用手機就能看。」

---

## 示範前檢查清單

### 前 3–5 天
- [ ] **先拿到客戶 2–3 張真實平面圖**（DWG／DXF 最好，其次是乾淨的 PDF 或 591 那種格局圖；手繪水彩、手機翻拍最弱）。
      開口方式：「想直接用貴公司的案子示範，可以先給我兩三張平面圖嗎？只用在示範和我們內部測試，不會外流；
      您希望的話，示範後我們就刪掉。」（我們會把圖留在私人測試庫做演練，見 T-013，所以要先講清楚並取得同意。）
- [ ] 在自己電腦本機演練：`QA_FIXTURES=… node qa/rehearse.mjs <檔案路徑>`（AI 用模擬，不花錢；檔案不上傳、不進 git）。
      看房間數、坪數、家具是否合理；有問題先記在 [`docs/board/T-007-demo-kit.md`](board/T-007-demo-kit.md)。
- [ ] 用正式站把其中 1–2 張**實際上傳一次**，做成「備用專案」：
  - [ ] 房間名稱正確（在編輯器點房間改名），「檢查」裡的「全部補上」先按過。
  - [ ] 選好最適合的風格（會存到專案：業主的連結和提案書都以這個風格與總價開啟），按 **✦ 一鍵產生提案圖**（約 NT$12／3 張），再在客廳多拍 1–2 個好角度（✦ 產生目前視角）。
  - [ ] 專案卡填上**業主名稱**；在 3D 右上按**分享**（或專案卡「分享」），用自己手機**掃 QR code** 打開看一次：應該是剛選的風格和同樣的總價。
  - [ ] 打開**提案書**，列印預覽確認 A4 版面。
- [ ] **AI 服務狀態**（取代以前花 NT$4 試出一張圖）：登入後打開 `/projects?check`（只有這個網址會打開，設計師的我的專案頁不顯示）。
      免費檢查兩把金鑰都顯示「金鑰有效」後，按 **確認額度**（實際呼叫一次、不出圖，不到 NT$0.5）。
      兩行都是「可用（已確認額度）」就 OK。
      「Google 專案是免費方案」→ 到 Google AI Studio 為 `GEMINI_API_KEY` 的專案開啟付費（免費方案不能出圖）；
      「餘額不足」→ 到 Claude Console 加值；「伺服器沒有設定金鑰」／「金鑰無效」→ 到 Vercel 專案設定換金鑰後重新部署。
      顯示「無法確認額度」時才在備用專案按一次「✦ 產生目前視角」（約 NT$4）確認。

### 前一天
- [ ] 示範帳號的**公司資料**填好：公司名稱、Logo（PNG 透明底最好）、電話、LINE、Email、地址、統一編號、品牌色。
      最有效的是填**客戶公司**的名稱與 Logo（先徵得對方同意，示範後改回），讓他們看到分享連結和提案書上是自己的品牌；
      沒有同意就用一個中性的示範品牌。
- [ ] 我的專案 → **價目表**：填價目表名稱與價格基準月份；材質單價（地坪、牆面每坪或每 m²，檯面、櫥櫃每公尺）、
      損耗、要用的**工程項目**打勾（例如保護工程、垃圾清運）。客戶事先給過價目表就照它輸入幾個主要項目；沒有就保留預設單價。
      儲存後打開備用專案 3D，按「查看清單」確認單價已換掉，再按一次「Excel 報價單」確認能下載、能用 Excel 打開。
      （若對話框顯示「價目表即將開放」並且不能儲存，代表資料庫還沒更新：示範時跳過 Excel 那一段，只講報價清單。）
- [ ] 我的專案清單整理乾淨：只留備用專案與 1 個示範專案，刪掉測試用的。
- [ ] 在備用專案以外，**不要**按「核准此方案」或切換風格做實驗：風格會存到專案（業主的連結以最後選的風格開啟），核准章記在這台電腦。

### 示範當天（出發前 1 小時）
- [ ] 筆電接電源（用電池時 GPU 會降頻，3D 會卡），Chrome 最新版，關掉其他分頁與視訊軟體。
- [ ] Chrome 設定 → 隱私權 → 清除瀏覽資料：**只勾「快取圖片和檔案」**，不要勾 Cookie（會被登出）。
- [ ] 清完快取後，**把每個要用的頁面完整打開一次預熱**：我的專案、備用專案 3D、AI 效果圖、提案書、`/?p=apartment` 示範宅。
- [ ] 確認右上角是「我的專案」而不是「登入」；登入過期就重新登入（登入過期時，打開專案會跳回示範宅）。
- [ ] 打開 `/projects?check` 再看一次 AI 服務狀態（免費，幾秒）：兩行都是綠點或「金鑰有效」就好；有紅點就準備用備用專案的效果圖。
- [ ] 手機：掃備用專案 3D 裡「分享」的 QR code 測一次；開好**手機熱點**當備援網路。
- [ ] 要上傳的客戶圖檔放在桌面，檔名看得懂（例如 `王公館-平面.dwg`）。

### 開場前 5 分鐘
- [ ] 分頁順序固定：① 我的專案 ② 備用專案 3D（探索模式）③ 備用專案 AI 效果圖 ④ 提案書 ⑤ 示範宅 `/?p=apartment#explore`。
- [ ] 語言切到「繁中」；瀏覽器縮放 100%；投影時用全螢幕（F11）。
- [ ] 手機已連網、螢幕亮度調高、勿擾模式。

## 分鐘腳本

| 時間 | 動作（點哪裡） | 說什麼 | 客戶該注意到 |
|---|---|---|---|
| **0:00–1:00** 開場 | 停在 ① 我的專案 | 「現在出一套提案，從平面圖、3D 到效果圖，貴公司大概要幾天？」（聽答案）「今天我直接用你們的圖，15 分鐘走完。」 | 這是他們的流程問題，不是我們的產品介紹 |
| **1:00–2:30** 上傳 | 把客戶的圖拖進「上傳平面圖」框 | 「DWG、DXF、PDF、照片都可以。DWG 在瀏覽器裡就轉檔，圖不會傳到別的地方。」 | 進度畫面一步一步打勾：讀圖 → 牆體門窗 → 房間 → 家具 → 儲存 |
| | 等進度畫面（DWG/DXF 約 2–5 秒，圖片約 30–45 秒含 AI） | 圖片檔等 AI 時：「它在認房間名稱，順便把圖上畫的家具讀出來，照圖擺。」 | 房間數、家具數、秒數的總結 |
| **2:30–4:30** 3D 探索 | 倒數 5 秒自動進 3D（或按「開啟 3D 導覽」） | 「這就是剛剛那張圖。點地板就走過去，左上角是小地圖。」 | 房間名稱、m² 和**坪**；家具位置跟圖一致 |
| | 點下方房間按鈕（客廳 → 主臥）；切「鳥瞰」看整層 | 「每間的坪數都算好了，跟你們平面圖對得上。」 | 鳥瞰時整層的格局 |
| | 切「平面圖」分頁 | 「同一份資料也出平面圖和坪數表。」 | 房間表 m²／坪 |
| **4:30–6:00** 風格 | 回「探索」，右側「風格」點 **侘寂風**，再點 **奶油風**；最後停在要給業主看的那一個 | 「一鍵換整套材質、布料、燈光，價錢跟著變。最後選的這個會存在專案裡，業主打開連結和提案書看到的就是它。」 | 畫面掃過去換風格，總價跳動 |
| | 對某個風格按 **A/B** | 「客戶猶豫兩個風格時，直接左右對比，差價寫在下面。」 | 分割畫面＋差價 |
| **6:00–7:30** 報價 | 按「查看清單」 | 「地坪、牆面、檯面都是從圖算出來的，含損耗，未稅、5% 營業稅、含稅分開列。」 | 數量是算出來的，不是估的 |
| | 點報價下方的 ⓘ | 「單價用的是貴公司自己的價目表，在『我的專案 → 價目表』設定，材質、工程項目、家具都可以改。」 | ⓘ 裡寫的是**貴公司的價目表名稱**，不是示範價目表 |
| | 按「Excel 報價單」（報價區中間的按鈕） | 「一鍵下載 Excel 報價單：依工種和房間分組，項目、規格、數量、單位、單價、複價，小計、營業稅、含稅總計都在。數量乘單價都是公式，你在 Excel 改數量，總價會跟著變。」 | 下載的檔案用 Excel 打開：抬頭是貴公司名稱與聯絡方式；這個按鈕只有設計師看得到，業主的分享連結上沒有 |
| **7:30–10:00** AI 效果圖 | 右上「✦ AI 效果圖」→ **✦ 一鍵產生提案圖** | 「它會自動找客廳、餐廳、主臥最好的角度拍下來，送去出實景圖，大約 30–40 秒。」 | 先看到 3D 畫面，再一張張變成實景 |
| | 等待時切回 ② 分頁或聊天 | 「牆、門窗、家具位置都鎖住，只換材質和光線，所以不會畫出一個不存在的窗。」 | 幾何是合約，不是 AI 亂畫 |
| | 圖出來後拖中間的滑桿 | 「左邊即時 3D，右邊效果圖，同一個角度。」 | 前後對比 |
| **10:00–11:30** 分享 | 不用離開 3D：右上 **分享**（三個圓點連線的圖示）→ 請客戶用手機相機**掃 QR code**；要傳給不在場的人就按「LINE 分享」或「複製」 | 「業主拿到的是唯讀連結，可以自己走、自己換風格看價錢，但改不到你的圖。打開就是我們剛剛選的風格和這個總價。」 | 手機打開是**貴公司的 Logo 和名稱**、剛選的風格（標著「設計師提案」）和**同樣的總價** |
| | 請客戶在自己手機上點「開始導覽」，換一個風格看看 | 「不用裝 App，掃一下就能看。您在手機上換風格不會改到我們的提案，按『回到設計師的提案』就回來。」 | 他自己在手機上操作；設計師的提案不受影響 |
| **11:30–13:00** 提案書 | 3D 右上「提案書」（文件圖示，不是旁邊的「提案」）或切 ④ 分頁 | 「這是給業主的提案書：效果圖、平面、坪數表、材質、報價、簽名欄。」 | 封面有業主名稱、日期、坪數；報價未稅／含稅 |
| | 按「列印／存成 PDF」 | 「A4 直式，直接存 PDF 傳給業主或印出來簽。要改報價就按旁邊的『Excel 報價單』，拿去你們自己的報價流程。」 | 列印預覽是乾淨的 A4；Excel 報價單只在設計師自己的提案書預覽上出現 |
| **13:00–15:00** 收尾 | 停在提案書 | 「如果貴公司每個月接 N 個案子，每案省下兩三天出 3D 和效果圖的時間。我們想用貴公司接下來 2–3 個真案子試用。」→ 進入「要問客戶的問題」 | 下一步是**具體的試用** |

## 出狀況時怎麼救

| 狀況 | 怎麼看出來 | 現場動作 | 可以說 |
|---|---|---|---|
| **AI 效果圖很慢**（> 60 秒） | 狀態列一直顯示「AI 正在生成…」 | 不要乾等：切到 ③ 備用專案 AI 效果圖分頁展示已做好的圖；回來時通常已完成 | 「它在跑，我先給您看上週同樣流程出的圖。」 |
| **AI 效果圖失敗** | 狀態列「X 張完成，Y 張失敗。」＋原因 | 「AI 這次太久沒有回應」→ 再按一次；「忙碌或已達上限」／「尚未啟用」→ 不要重試，直接用 ③ 備用分頁 | 「AI 服務那邊塞車，我們用剛剛那組。」 |
| **房間辨識不好**（房間少、名稱怪、牆沒接上） | 進度總結的房間數不對；3D 有缺牆 | 在進度畫面按「先檢查平面」→ 右側「檢查」→ **全部補上**；房間名稱直接點房間改；看到右上「已儲存到帳號」後按「在 3D 中查看」（已登入時會開啟這個專案，有 AI 效果圖和提案書；沒登入或沒存成功才會開本機預覽，沒有這兩個功能） | 「這張圖的牆線有斷開，一鍵補上……這就是設計師會做的 30 秒檢查。」 |
| **完全找不到牆**（手繪、翻拍、很淡的圖） | 「需要你幫一下：這張圖找不到清楚的牆線」 | 不要現場描牆：改開 ② 備用專案（同一位客戶的另一張圖） | 「這張是手繪掃描，我們建議用 CAD 或 PDF；換您另一張圖看。」 |
| **DWG 轉檔失敗** | 進度畫面顯示 DWG 錯誤訊息（版本太舊／檔案損壞） | 請對方從 AutoCAD 另存成 DXF 或 2018 版 DWG；現場先用備用專案 | 「這個檔案版本比較舊，存成 DXF 就可以，我先用另一張。」 |
| **網路斷線／很慢** | 頁面轉圈、效果圖狀態「網路連線中斷…請確認網路後再按一次」 | 筆電切到手機熱點；已預熱的分頁（3D、AI 效果圖、提案書）大多可以繼續操作，但上傳與出圖需要網路 | 「我切一下網路。」 |
| **3D 卡頓** | 走動一頓一頓 | 確認接電源；網址最後加 `&q=med`（或 `&q=lite`，例如 `/?id=…&q=med#explore`）重新整理 | （不用解釋，直接換） |
| **打開專案卻跑出示範宅** | 標題不是專案名稱、跳出「找不到這個專案，請先登入」 | 登入過期：右上角重新登入 → 我的專案 → 重開專案 | 「我重新登入一下。」 |
| **客戶手機打不開連結** | LINE 內建瀏覽器打不開或很慢 | 請客戶改用手機相機掃 3D 裡「分享」的 QR code（會用預設瀏覽器開），或 LINE 的「以預設瀏覽器開啟」；或直接把自己手機遞給他 | 「用 Safari／Chrome 開會比較順。」 |
| **風格沒有存到帳號** | 3D 跳出「風格沒有存到帳號（網路中斷？）…」 | 切到手機熱點，再點一次風格或按「分享」（會重試）；客戶的連結在存好之前仍是先前的風格 | 「我切一下網路。」 |
| **3D 跳出「尚未儲存到帳號，先開本機預覽」** | 從編輯器按「在 3D 中查看」時沒存成功 | 這個預覽沒有 AI 效果圖、提案書和分享：回「編輯平面」，等右上「已儲存到帳號」再按一次；網路有問題就切熱點 | 「我先存一下檔。」 |
| **一切都不行** | — | 開 ⑤ 示範宅 `/?p=apartment`：導覽動畫、風格、A/B、AI 效果圖、提案模式全部是內建的 | 「我用我們的示範案把剩下的流程走完。」 |

## 要問客戶的問題（收集試用條件）

**平面圖**
1. 平常拿到的平面圖是什麼格式？（DWG／DXF／PDF／紙本掃描／591 那種格局圖）AutoCAD 哪一版？
2. 一個案子通常幾層？有沒有透天、夾層？

**報價**
3. 有沒有自己的**價目表**？是 Excel 嗎？可以給我一份（可遮掉價格）讓我們照格式做？（可以直接輸入到「我的專案 → 價目表」，報價、提案書和 Excel 報價單就用他們的單價）
4. 報價單是含工帶料還是分開？報價時要不要分「未稅／含稅」？

**提案**
5. 現在給業主的提案長什麼樣？（PDF、簡報、紙本、LINE 傳圖）可以給我看一份嗎？
6. 3D 和效果圖是自己畫還是外包？一張效果圖多少錢、等幾天？

**量與流程**
7. 每個月大概接幾個案子？同時有幾個設計師在出提案？
8. 從第一次見業主到簽約，平均要幾次提案？

**決策**
9. 決定要不要用新工具的是誰？要簽的是誰？（老闆、合夥人、會計）
10. 如果試用 2–3 個真案子，什麼結果會讓你們決定用？

**下一步（現場就約）**：拿到 2–3 個進行中案子的圖 → 我們建好專案和效果圖 → 一週後一起看業主反應。

## English summary

A 15-minute founder-led demo for a Taiwan design-firm owner, using the client's own plans:
upload (picture/PDF/DXF/DWG) → progress screen → 3D walk with m²/坪 → one-click style switch and A/B with live
quote (未稅 / 5% tax / 含稅) → ✦ one-click AI renders (≈30–40 s) → 分享 in the 3D top bar: the client scans the QR code
(or gets it via LINE) and the read-only, firm-branded link opens in the style the designer last picked, with the same
total (T-010, T-011) → printable A4 提案書 (quotes the same style) → close on a 2–3 project pilot. The quote uses the firm's own price list
(我的專案 → 價目表, set the day before; ⓘ under the total names it) and 「Excel 報價單」 downloads an editable 報價單
with live formulas — designer only, not on the client's share link (T-003; skip it if the price-list migration is not live). Prices are not quoted on site (owner decision).

Preparation is what makes it flawless: get 2–3 of the client's plans days ahead, rehearse them locally with
`node qa/rehearse.mjs <file>` (AI stubbed, nothing committed), then import 1–2 for real on the live site as a prepared
